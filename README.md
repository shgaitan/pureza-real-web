# Pureza Real Hub

Creemos una pagina web sobre Pureza Real, agregaremos un quienes somos y que vendemos, nuestros puntos de venta fisico; asi como una parte de catalogo con pasarela de pago y un apartado de blog ya que la marca es bastante educacional.  Te comparto brief de marca y el branding de la marca con sus logos, colores y tipografia
