# Pureza Real website

- Build a Spanish multi-page website using the supplied brand identity and warm educational voice.
- Include Home, Nosotros, Catálogo, Puntos de venta, and Blog.
- Use the official logo, Borel headings, DM Sans body, and supplied palette.
- Configure real checkout only after products, pricing, delivery scope, and payment provider are confirmed.
- Use separate TanStack routes for Home, Nosotros, Catálogo, Puntos de venta, and Blog because each section must be shareable and searchable.
- Keep commerce data outside page components so products and checkout can later connect to Lovable Cloud or a commerce provider.
